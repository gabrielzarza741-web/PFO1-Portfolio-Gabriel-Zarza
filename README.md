# PFO1 · Portafolio de Gabriel Zarza

Landing personal desarrollada con HTML semántico, CSS propio y una pequeña interacción en JavaScript para preparar un correo. Presenta mi perfil de estudiante, conocimientos en formación, una sección personal vinculada al servicio como bombero y formas de contacto.

- Sitio en Vercel: **Pendiente de publicar y pegar aquí la URL real.**

## Ejecutar

Descomprimir el ZIP y abrir `index.html` en el navegador. No requiere instalar paquetes ni compilar. Google Fonts requiere conexión; hay fuentes alternativas del sistema.

## Archivos

- `index.html`: estructura y contenido.
- `styles.css`: diseño y adaptación a pantallas.
- `script.js`: prepara el correo del formulario.
- `identidad.svg`: ilustración vectorial de iniciales.

## Decisiones de diseño

La propuesta inicial utiliza un fondo oscuro y un acento verde para diferenciar títulos, enlaces y acciones. Las fuentes son Space Grotesk y DM Sans, cargadas desde Google Fonts. Se usaron Grid y Flexbox para ordenar contenido, media queries para pantallas pequeñas, un enlace para saltar al contenido y estados de foco visibles. Los botones tienen una transición y se respeta la preferencia de movimiento reducido.

La sección personal relaciona tecnología y vocación de servicio. Las habilidades se presentan como conocimientos en formación, sin inventar niveles profesionales. La ilustración SVG evita utilizar una fotografía personal sin selección expresa.

El formulario cuenta con etiquetas, validación nativa y campos obligatorios. Abre la aplicación de correo mediante `mailto:`; no guarda datos ni envía mensajes automáticamente. El visitante debe confirmar el envío en su aplicación de correo. El enlace directo de correo funciona como alternativa.
